# SupportEmgine

Multi-Agent Customer Support Resolution Engine — classifies, investigates, resolves, and escalates e-commerce support tickets with parallel AI agents.

**All application code lives in [`techathon-main/`](./techathon-main/).**

## Get started

```bash
cd techathon-main
npm install
copy .env.example .env    # then add your Groq API key
npm run dev:all
```

Full setup, env vars, and troubleshooting: **[techathon-main/README.md](./techathon-main/README.md)**  
Prerequisites checklist: **[techathon-main/requirements.txt](./techathon-main/requirements.txt)**

| Service | URL |
|---------|-----|
| Frontend | http://localhost:3100 |
| API | http://localhost:4100 |
| Agent | http://localhost:5000 |

Groq free API key: [console.groq.com/keys](https://console.groq.com/keys)
